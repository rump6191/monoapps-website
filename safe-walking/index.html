Safe Walking

야간 안전 보행 길찾기

야간 보행자, 여성, 1인 가구를 위한 안전 경로 추천 서비스입니다. CCTV, 가로등이 많은 안전한 길로 안내하고, 보호자에게 실시간 위치를 공유합니다.

📹 CCTV 커버리지 💡 가로등 밝은 길 📍 실시간 위치 공유 🚨 긴급 신고

주요 기능

안전한 야간 귀가를 위한 모든 기능

🗺️ 안전 경로 추천

CCTV, 가로등, 편의점이 많은 안전한 길을 우선 추천합니다. 안전 점수로 경로의 안전도를 한눈에 확인할 수 있습니다.

📊 실시간 안전 점수

CCTV, 가로등, 치안, 유동인구, 편의시설 등을 종합 분석하여 100점 만점의 안전 점수를 제공합니다. 위험 구역은 자동 회피합니다.

🏠 귀가 시작

귀가를 시작하면 등록된 보호자에게 실시간 위치가 공유됩니다. 예상 소요 시간을 선택하고 안전하게 귀가하세요.

📍 실시간 위치 공유

귀가 중 보호자에게 실시간으로 위치가 공유됩니다. 시작 시간, 예상 도착 시간을 확인하고 안전하게 도착하세요.

이용 방법

간단한 4단계로 안전하게 귀가하세요

1
로그인
카카오/구글 간편 로그인
2
목적지 설정
집, 회사 등 즐겨찾기 선택
3
귀가 시작
보호자에게 위치 공유 시작
4
안전 귀가
실시간 안내 따라 귀가 완료

카카오 API 사용 목적

본 앱은 다음과 같은 목적으로 카카오 API를 사용합니다:

  • 카카오맵 API: 지도 표시 및 안전 경로 안내
