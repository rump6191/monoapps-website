계정 및 데이터 삭제 요청

사주프라임 앱에서 수집한 계정 및 사용자 데이터를 삭제하는 방법을 안내합니다.

1. 앱 내에서 로컬 데이터 삭제

기기에 저장된 분석 기록과 사진은 앱에서 즉시 삭제할 수 있습니다:

  1. 사주프라임 앱 실행
  2. 설정 화면으로 이동
  3. 기록 삭제 선택 후 확인
✓ 즉시 삭제되는 데이터(로컬)
분석 기록, 관상 분석 결과 이미지(기기 내 저장본), 입력했던 사주 정보, 앱 설정. 앱을 삭제하면 기기의 모든 로컬 데이터가 함께 제거됩니다.

2. 계정 및 서버 데이터 삭제 요청 (이메일)

소셜 로그인으로 만든 계정 정보, 코인 잔액, 서버 측 데이터는 이메일 요청으로 삭제할 수 있습니다.

이메일 수신자:

admin@monoapps.kr

요청 시 포함 내용:

  • 제목: [사주프라임] 계정 삭제 요청
  • 가입에 사용한 로그인 이메일(구글/애플/카카오/라인)
  • 게스트로 이용한 경우, 가능하면 구매 영수증 정보

저희는 14영업일 이내에 계정·서버 데이터를 삭제하고 완료 확인 이메일을 보내드립니다.

3. 삭제되는 데이터 유형 및 보관 기간

데이터 유형 삭제 방법 추가 보관 기간

⚠️ 주의사항
• 앱을 삭제하면 기기의 로컬 데이터는 모두 삭제되지만, 서버 데이터(계정·코인 등)는 자동 삭제되지 않으므로 위 이메일 요청이 필요합니다.
• 정기결제는 없으나, 구매한 코인 잔액은 계정 삭제 시 함께 소멸되며 환불되지 않습니다.
• 법령에 따라 보관이 의무화된 데이터(예: 전자상거래법상 거래 기록)는 보관 기간이 경과한 후 삭제됩니다.

Account & Data Deletion Request

How to delete your account and data collected by the SajuPrime app.

1. Delete local data within the app

  1. Open the SajuPrime app
  2. Go to Settings
  3. Select Clear History and confirm
✓ Data deleted immediately (local)
Analysis history, physiognomy result images stored on the device, entered Saju details, and app settings. Uninstalling the app removes all local data on the device.

2. Request account & server data deletion (email)

Account information created via social login, coin balance, and server-side data can be deleted by email request.

Recipient: admin@monoapps.kr

  • Subject: [SajuPrime] Account Deletion Request
  • The login email used to sign in (Google / Apple / Kakao / LINE)
  • If you used the app as a guest, include a purchase receipt if available

We will delete your account and server data within 14 business days and send a confirmation email.
