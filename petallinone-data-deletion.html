사용자 데이터 삭제 요청

펫케어 앱에서 수집한 사용자 데이터를 삭제하는 방법을 안내합니다.

1. 앱 내에서 직접 삭제 (권장)

펫케어 앱에서 모든 로컬 데이터를 즉시 삭제할 수 있습니다:

  1. 펫케어 앱 실행
  2. 하단 설정 탭으로 이동
  3. 데이터 관리 → 데이터 초기화 선택
  4. 확인 다이얼로그에서 2회 확인 후 삭제 실행
✓ 즉시 삭제되는 데이터
반려동물 프로필, 산책 기록, 체중 기록, 예방접종 기록, AI 건강 분석 결과, 앱 설정(언어/알림 등), 기기에 저장된 반려동물 사진 경로 정보

2. 서버 데이터 삭제 요청 (이메일)

구독 정보, 디바이스 ID 등 서버에 저장된 일부 데이터는 이메일 요청으로 삭제할 수 있습니다.

이메일 수신자:

admin@monoapps.kr

요청 시 포함 내용:

  • 제목: [펫케어] 데이터 삭제 요청
  • 디바이스 ID (선택, 앱 설정 화면에서 확인 가능)
  • 가능한 경우 구매 영수증 정보 (구독자의 경우)

저희는 14영업일 이내에 서버 데이터를 삭제하고 완료 확인 이메일을 보내드립니다.

3. 삭제되는 데이터 유형 및 보관 기간

데이터 유형 삭제 방법 추가 보관 기간
반려동물 프로필 / 산책 / 체중 / 예방접종 기록 앱 내 '데이터 초기화' 없음 (즉시 삭제)
AI 건강 분석 결과 (로컬) 앱 내 '데이터 초기화' 없음 (즉시 삭제)
AI 분석 요청 서버 로그 이메일 요청 최대 30일 (이후 자동 익명화)
구독 정보 (RevenueCat / 기기 ID 연동) 이메일 요청 결제·환불·법적 의무 이행을 위해 최대 5년 (세법 규정)
광고 ID (AdMob) 기기 설정에서 직접 리셋 해당 없음 (Google이 관리)
앱 크래시 로그 및 진단 정보 앱 삭제 시 수집 중단 최대 90일 후 자동 삭제
⚠️ 주의사항
• 앱을 삭제하면 기기의 로컬 데이터는 모두 삭제되지만, 서버 데이터(구독 정보 등)는 자동 삭제되지 않습니다.
• 구독 해지는 Google Play / Apple App Store의 구독 관리 메뉴에서 별도로 진행하셔야 합니다.
• 법령에 따라 보관이 의무화된 데이터(예: 전자상거래법상 거래 기록)는 보관 기간이 경과한 후 삭제됩니다.

User Data Deletion Request

How to delete data collected by the PetCare app.

1. Delete directly within the app (recommended)

  1. Open the PetCare app
  2. Go to Settings (bottom tab)
  3. Select Data Management → Reset Data
  4. Confirm twice in the dialogs to execute deletion
✓ Data deleted immediately
Pet profiles, walk records, weight records, vaccination records, AI health analysis results, app settings (language, notifications), and local photo references.

2. Request server data deletion (email)

Subscription information and device ID stored on our servers can be deleted by email request.

Recipient: admin@monoapps.kr

  • Subject: [PetCare] Data Deletion Request
  • Device ID (optional, found in app Settings)
  • Purchase receipt (for subscribers, if available)

We will delete server data within 14 business days and send a confirmation email.

⚠️ Notes

• Subscription cancellation must be done separately via Google Play / Apple App Store.
• Data required by law (e.g., e-commerce transaction records) is retained for the legally mandated period before deletion.
