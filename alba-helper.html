주요 기능

알바생을 위한 모든 것

📅

근무기록 관리

캘린더에서 날짜를 선택해 출퇴근 시간, 시급, 휴게시간, 메모를 기록하세요. 근무 내역이 한눈에 보입니다.

💰

급여 자동 계산

시급과 근무시간을 입력하면 이번 달 예상 급여를 실시간으로 계산해 드립니다.

🏖️

주휴수당 계산

주 15시간 이상 근무하면 발생하는 주휴수당을 자동으로 산정합니다. 근무 기록에서 주간 시간을 자동으로 불러옵니다.

🧾

3.3% 세금 계산

프리랜서·일용직 원천징수 세금을 계산합니다. 총 급여에서 실수령액이 얼마인지 바로 확인하세요.

📊

급여일지

월별 총 급여, 근무일수, 총 근무시간을 한눈에 확인할 수 있는 급여 상세 내역을 제공합니다.

🔔

급여일 알림

급여일을 설정하면 하루 전에 알림을 보내드립니다. 급여일을 절대 잊지 마세요. (프리미엄 기능)

근무기록을 캘린더로

매일의 근무 내역을 캘린더에 직접 기록하세요. 출퇴근 시간, 시급, 휴게시간을 입력하면 하루 급여가 자동으로 계산됩니다.

  • 출퇴근 시간 & 시급 입력
  • 휴게시간 공제 자동 반영
  • 근무별 메모 기능
  • 캘린더에 근무일 표시

주휴수당, 이제 쉽게

주 15시간 이상 근무하면 유급 주휴일이 발생합니다. 복잡한 계산은 앱이 대신 해드립니다. 이번 주 근무 기록에서 자동으로 시간을 불러와 계산합니다.

  • 주간 근무시간 자동 집계
  • 주휴수당 발생 여부 즉시 확인
  • 추가 근무 필요 시간 안내
  • 계산 방식 상세 설명

3.3% 세금도 한 번에

프리랜서나 일용직으로 일하면 3.3% 원천징수 세금이 공제됩니다. 총 급여를 입력하면 세금 내역과 실수령액을 바로 알 수 있습니다.

  • 소득세 3% + 지방소득세 0.3%
  • 총 급여 → 실수령액 즉시 계산
  • 세금 내역 상세 보기
  • 연말정산·환급 안내 정보
