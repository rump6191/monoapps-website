Core Features

Everything you need to navigate Korea's public transit system with confidence

🔍 Easy Search

Bilingual Search: Type in English, find Korean stations instantly. View station names in both English and Korean with convenient recent search history.

🚇 Smart Route Options

Optimized Routes: Choose between fastest route, fewest transfers, or cheapest fare. See detailed time, transfer count, and cost for each option.

📍 Step-by-Step Guidance

Clear Directions: Follow detailed walking → subway → transfer instructions with bilingual station names displayed at every step.

🔔 Real-time Navigation

Arrival Alerts: Live navigation with smart alighting alerts and voice guidance. Never miss your stop again.
